# 鴻門之会 ドリル

史記「鴻門之会」のプリントを、そのまま練習できる学習アプリ。

**→ https://ahaaaaa34.github.io/komin3/**

## インストール（PWA）

ホーム画面に追加すると、アプリとして全画面で開き、電波がなくても使える。

- **iPhone / iPad**：Safari で開く → 共有ボタン［↑］→「ホーム画面に追加」
- **Android / PC**：Chrome で開く → ヘッダーの「＋ ホーム画面に追加」ボタン（またはアドレスバーのインストールアイコン）

インストール後は、アイコンを長押しすると 読み / 指示語 / 座席 / 本文 に直接飛べる。
`#yomi` `#shiji` `#work` `#seki` `#bunpou` `#text` を URL につけても同じ。

ファイル構成は `index.html`（本体・1ファイル）、`manifest.json`、`sw.js`（オフライン用）、`icon-*.png`。

## 6つのタブ

| タブ | 中身 | もとになったプリント |
|---|---|---|
| 読み | 赤い線を引いた語の読み（①〜⑫＋語注）全18問 | プリント1・2 |
| 指示語 | オレンジの丸＝その語が指すもの。囲みの語も含めて11問 | プリント1・2 |
| ワーク | 語句1「旦日」・語句2「小人」（読み＋意味）、句法2「若属皆且為所虜」の書き下し文 | 問題集 上1・2／下2 |
| 座席 | 6人（項王・項伯・亜父＝范増・沛公・張良・項荘）を東西南北に置く。一問一答11問 | 座席図 |
| 句法 | 使役・受身・再読文字・反語・判断・可能・置き字・一人称/二人称の8項目。例文はすべて本文から | — |
| 本文 | 前後のあらすじ、白文（縦書き）・書き下し文・現代語訳・段落解説、故事成語、出典（史記） | — |

## 解答後に出る解説

1問ごとに、意味 → 書き下し文 → 現代語訳 → 句法のまとめ → 解説 → 覚えるコツ、の順で出る。
書き下し問題（若属皆且為所虜）は、語を5段階に分けた手順つき。

## 覚えかたのポイント

- **「◯嚮」は向きで、位置ではない。** 東嚮＝東を向く＝**西がわ**にすわる。図と本文が逆になるので注意。
- 上座の順は 東嚮（項王・項伯）＞南嚮（亜父）＞北嚮（沛公）＞西嚮（張良）。客の沛公が下座に置かれている。
- 同じ「此」「之」でも指す内容が変わる。場所か、事態か、人かを見分ける。

## 進み具合

正解・不正解は端末の localStorage に保存される。タブの数字が正解数。「まちがえた問題だけ」でもう一周できる。
